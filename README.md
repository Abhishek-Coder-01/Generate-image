# AI Image Generator

## Overview

This web application allows users to generate images from text prompts using the **Nebui.studio API**. Built with **HTML**, **Tailwind CSS**, and **JavaScript**, it provides a modern interface with **icons** and a **scrollable image gallery** for displaying results.

---

## Features

- **Text-to-Image Generation** – Create images from any text prompt.
- **Light/Dark Mode** – Toggle between light and dark themes.
- **Interactive Icons** – Buttons for Generate, Download, Delete, and Copy.
- **Scrollable Image Gallery** – View multiple generated images in a scrollable container.
- **Aspect Ratio Selection** – Choose the preferred image size and ratio.
- **Negative Prompt Support** – Exclude unwanted elements from generated images.
- **Responsive Design** – Works on mobile, tablet, and desktop.
- **Loading Animation** – Spinner icon while images are being generated.
- **Prompt History** – Keeps track of previously used prompts.

---



## Technologies Used

- **HTML5** – Structure and layout.
- **CSS3** – Styling.
- **Tailwind CSS** – Utility-first framework for responsive design.
- **JavaScript (ES6+)** – Handles API calls and UI logic.
- **Font Awesome / Heroicons** – Icons for buttons and actions.
- **Nebui.studio API** – AI-powered image generation.
- **GitHub Pages** – Hosting the live demo.
